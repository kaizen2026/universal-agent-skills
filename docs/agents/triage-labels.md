# Triage labels

Use these canonical **Triage role** mappings for issues in `kaizen2026/universal-agent-skills`.

| Triage role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer evaluation is required |
| `needs-info` | `needs-info` | Reporter information is required |
| `ready-for-agent` | `ready-for-agent` | Fully specified and available for an agent |
| `ready-for-human` | `ready-for-human` | Human action is required |
| `wontfix` | `wontfix` | The issue will not be actioned |

Apply only the role appropriate to the issue's current state.
